API Endpoints Overview

GET /sources Videasy decrypted streams (Yoru, Neon, Cypher, Breach)
GET /moviebox/sources Moviebox MP4 & DASH streams + CDN captions
GET /moviebox/search Search Moviebox title catalog
GET /player Interactive HTML5 Web Player
GET /proxy Stream CORS proxy & DASH .m4s segment wrapper
