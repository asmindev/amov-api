# Videasy Decryptor — Enterprise Architecture Redesign

## User Decisions
- **HTML**: Extract ke Jinja2 templates
- **API Versioning**: Tanpa prefix (/sources, /proxy — bukan /api/v1/sources)
- **DASH State**: Encode base_dir + headers di URL path → stateless, thread-safe

---

## Current Problems
1. `application.py` = 1,382-line God file (routes + middleware + HTML + proxy + helpers)
2. Config hardcoded, no `.env` support
3. `app.state.last_dash_base` global → breaks under concurrency
4. No tests
5. Proxy logic duplicated
6. HTML inline ~700 lines di Python

## DASH State: Path-Encoded (Stateless)

Instead of global `app.state.last_dash_base`, encode base_dir + headers into the URL path:

**When MPD is fetched** → proxy_hls saves base info and rewrites initialization URLs:
```python
# Initialization URL di MPD:
# init-stream$RepresentationID$.m4s
# 
# rewrite jadi:
# /dash/{token}/init-stream$RepresentationID$.m4s
# 
# token = base64url(base_dir + "|" + headers_json)
```

**When segment requested** → middleware decodes token:
```python
class DASHSegmentMiddleware:
    async def __call__(self, scope, receive, send):
        path = scope["path"]
        if path.startswith("/dash/"):
            token = path.split("/")[2]  # /dash/{token}/init-stream3.m4s
            base_dir, headers_json = decode_token(token)
            segment = "/".join(path.split("/")[3:])  # init-stream3.m4s
            target = base_dir + segment
            # proxy target with headers_json
```

**Benefits**: No global state, thread-safe, works with multiple concurrent users.

## App Factory (No Versioning)

```python
# videasy/app.py
from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware
from jinja2 import Environment, FileSystemLoader

def create_app() -> FastAPI:
    app = FastAPI(title="Videasy Decryptor", version="2.0.0")

    # Middleware (order matters: last added = first executed)
    app.add_middleware(CORSMiddleware, allow_origins=["*"], allow_methods=["*"], allow_headers=["*"])
    app.add_middleware(DASHSegmentMiddleware)

    # Templates
    templates_env = Environment(loader=FileSystemLoader("videasy/features/player/templates"))
    app.state.templates = templates_env

    # Routers (no /api/v1 prefix)
    from videasy.features.sources.routes import router as sources_r
    from videasy.features.moviebox.routes import router as moviebox_r
    from videasy.features.subtitles.routes import router as subtitles_r
    from videasy.features.player.routes import router as player_r
    from videasy.features.info.routes import router as info_r
    from videasy.proxy.routes import router as proxy_r

    for r in [sources_r, moviebox_r, subtitles_r, player_r, info_r, proxy_r]:
        app.include_router(r)

    register_exception_handlers(app)
    return app
```

## Migration Steps (Sequential)

### Step 1: Create package skeleton
```
mkdir -p videasy/{core,proxy,features/{sources,moviebox,subtitles,player/templates,info},models,integrations,utils}
```
Create all `__init__.py` files. Create `videasy/app.py` with empty `create_app()`.

- `pip install pydantic-settings`

- Split `app/models.py` → `videasy/models/source.py`, `subtitle.py`, `common.py`
